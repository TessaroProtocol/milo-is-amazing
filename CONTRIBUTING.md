# Contributing to milo-is-amazing

Thank you for believing Milo is amazing. Your contribution helps.

## Rules

1. One reason per pull request.
2. Reasons must be **true**, **verifiable**, or at minimum **extremely well-received**.
3. No reason may be a duplicate of an existing one in `README.md`. Check first.
4. Do not slander anyone. Especially not Milo.
5. Spelling is optional. Enthusiasm is not.

## Adding a reason

Open a pull request that adds a numbered item to the list in `README.md`, with your name in the commit message.

Example:

```
1. **Milo greets new people like old friends.**
```

## Reviews

All pull requests are reviewed by Milo, who approves everything, because Milo is generous and because Milo is amazing.
